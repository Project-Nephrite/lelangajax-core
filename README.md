## About LelangAjax

LelangAjax is an auction based e-commerce platform based in Indonesia. We believe that platform for everyone means that any individual can participate in the activity without any worry of being push aside. No merchant or company can take part with us, only individual person.

## This Repository

This repository maintains our core service, main business logic.
